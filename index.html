第二关 · 算术与逻辑

积木 → Python 计算 / 逻辑入门

这一关汇集了 20 个常用的运算、比较、逻辑、变量、输入积木，对应到 Python 里的 math 模块、内置函数 abs/round/input，以及 + - * / % == < > and or not 等运算符。

知识总结

数据类型（int / float / bool / str）
int整数，不带小数点x = 3
float小数（浮点数）y = 3.14
bool布尔值，只有 True / Falseb = True
str字符串，用引号包裹s = "hi"
算术运算（+ - * / // % **）
+加3 + 2 → 5
-减3 - 2 → 1
*乘3 * 2 → 6
/除（结果总是浮点数）3 / 2 → 1.5
//整除（向下取整）7 // 2 → 3
%取余（求余数）7 % 2 → 1
**幂（乘方）2 ** 3 → 8
比较运算（结果都是 bool）
==等于3 == 3 → True
!=!=3 != 2 → True
<小于2 < 3 → True
>大于3 > 2 → True
<=小于等于2 <= 2 → True
>=大于等于3 >= 2 → True
逻辑运算（and / or / not）
and与：两边都真才真True and False → False
or或：只要一个真就真True or False → True
not非：把真假反过来not True → False
变量命名规则
可用字符字母、数字、下划线 _（推荐全小写）name, score_1, _tmp
开头限制不能以数字开头score1（对）　1score（错）
区分大小写Age 与 age 是两个不同的变量Age != age
禁用关键字不能用 Python 关键字作变量名if, for, while, True, None（错）
推荐写法见名知意，多词用下划线连接（snake_case）student_name（对）　a, x1（错）
